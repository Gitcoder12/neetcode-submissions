# Contributing to neetcode-submissions

This repository is automatically synced from NeetCode. Preserve the sync workflow and generated submissions.

1. Read README.md and FEATURE_UPGRADE_PLAN.md.
2. Do not mass-reformat or rename generated solution files.
3. Add explanations or indexes in separate documentation files.
4. For a solution correction, identify the exact problem and explain the bug before changing it.
5. Add tests or examples that do not require platform credentials.
6. Keep automated sync changes and manual changes distinguishable in the PR.

Never commit NeetCode credentials, personal tokens or other secrets. Human maintainer approval is required.
