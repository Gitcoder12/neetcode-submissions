# neetcode-submissions — Company and Team Fit

Potential interview-preparation and skills fit only, not evidence these companies use this repository.

## Project thesis

A collection of your coding interview problem submissions synced from NeetCode, so you can revisit problems and track the solutions you have written.

## Microsoft

**Relevant role areas:** Software engineering and interview-based developer roles.

**Potential roles:** Software Engineer, Backend Engineer, Systems Engineer, Data Engineer or Graduate Engineer.

**Evidence to build:** README describes automatic GitHub Sync from NeetCode.io. This repository is populated by an external submission-sync workflow; local documentation and agent contributions must avoid rewriting generated solution files or interfering with the upstream sync process. The portfolio value should be in correctness, complexity explanations and well-organised review notes, not claiming ownership of the platform.
