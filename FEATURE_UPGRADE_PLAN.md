# neetcode-submissions — Feature Upgrade Plan

## Objective

A collection of your coding interview problem submissions synced from NeetCode, so you can revisit problems and track the solutions you have written.

## P0 — protect sync and content integrity

- [ ] Document sync behavior, which files are generated and how manual edits interact with automatic updates.
- [ ] Add a consistent solution explanation format without mass-reformatting or overwriting synced submissions.

## P1 — make learning evidence stronger

- [ ] Add per-problem complexity notes and links to problem statements where licensing/terms permit.
- [ ] Add lightweight syntax/test checks grouped by language without changing accepted solution content.

## P2 — coverage and quality checks

- [ ] Track coverage by topic and difficulty with a generated index.
- [ ] Add curated edge-case tests and compare solutions to known examples; keep secrets and platform tokens out of repo.

## Definition of done

- [ ] Automated sync remains functional and generated files are preserved.
- [ ] Every manual explanation links to a problem and its own solution path.
- [ ] Language checks do not overwrite submissions.
- [ ] Complexity and acceptance claims are evidence-backed.
